CITY TECH CLOUD SERVER DEPLOY STEPS

This is the permanent shared server package.

Recommended deployment: Render Blueprint

1. Upload this folder to a GitHub repository.
2. In Render, choose New > Blueprint.
3. Select the repository with this folder.
4. Render will create:
   - citytech-cloud-server web service
   - citytech-db PostgreSQL database
   - DATABASE_URL environment variable
5. After deployment, open:
   https://YOUR-RENDER-URL/api/health
6. If it shows ok:true, enter the hosted URL in both apps:
   - Windows app: Shared server URL field
   - Android APK: Shared server URL field, or scan the QR shown by the hosted web app
